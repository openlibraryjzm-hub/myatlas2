# Shop Atlas Custom Images

Place your custom shop atlas cover images in this folder (`public/shop/`).

## Supported File Names & Formats:

Save image files using the item **ID** in `.png`, `.jpg`, `.jpeg`, or `.webp` format:

| Item Name | Target File Name Examples |
|---|---|
| **Tools** | `tools.png` or `tools.jpg` or `tools.webp` |
| **Addons** | `addons.png` or `addons.jpg` |
| **Assets** | `assets.png` or `assets.jpg` |
| **Media** | `media.png` or `media.jpg` |
| **Deals** | `deals.png` or `deals.jpg` |
| **Learn** | `learn.png` or `learn.jpg` |
| **Print** | `print.png` or `print.jpg` |
| **Steam Workshop** | `steam_workshop.png` or `steam_workshop.jpg` |
| **Nexus Mods** | `nexus_mods.png` or `nexus_mods.jpg` |
| **Minecraft** | `minecraft.png` or `minecraft.jpg` or `minecraft.webp` |
| **Team Fortress 2** | `tf2.png` or `tf2.jpg` |
| **Overwatch** | `overwatch.png` or `overwatch.jpg` |
| **Marvel Rivals** | `marvel_rivals.png` or `marvel_rivals.jpg` |
| **Roblox** | `roblox.png` or `roblox.jpg` |
| **Fallout 76** | `fallout76.png` or `fallout76.jpg` |
| **Halo Infinite** | `halo_infinite.png` or `halo_infinite.jpg` |
| **League of Legends** | `league_of_legends.png` or `league_of_legends.jpg` |

If a local image is present in `public/shop/`, it will automatically take precedence over the default fallback image.
